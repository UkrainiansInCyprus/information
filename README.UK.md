# Інформація для українців на Кіпрі
Цей репозиторій містить інформацію для українців на Кіпрі. Інформація в ньому постійно оновлюється, оскільки і обставини змінюються.
Внески вітаються у всі розділи репозиторію, включаючи:
- Вікі;
- Обговорення;
- Вихідний код (pull-requests/issues з запитами змін).

[English version of this README.md](README.md)

## Building the site
Цей сайт побудовано з використанням [Zensical](https://zensical.org/). Щоб побудувати сайт локально, вам потрібно встановити [Python](https://www.python.org/downloads/),
бажано з [uv](https://docs.astral.sh/uv/), оскільки uv використовується для менеджменту залежностей. (Альтернативно - ви можете запустити [Devcontainer](https://containers.dev/) наданий у цьому репозиторії з вашим редактором коду)

### 1. Встановлення залежностей
Виконайте команду:
```bash
uv sync
```
Ця команда синхронізує залежності з файлом `uv.lock`.

### 2. Збірка сайту
Для збірки сайту, виконайте:
```bash
uv run zensical build
```

### 3. Налагодження сайту
Для налагодження сайту, виконайте:
```bash
uv run zensical serve
```
Ця команда запустить локальний сервер, що позбавляє вас необхідності вручну сервіти статичні файли.
За інформацією в терміналі ви зможете дізнатися URL, за яким сайт буде доступний.
